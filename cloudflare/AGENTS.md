# 云端工作台协作约定

本目录是可独立部署的Cloudflare版本，运行于Worker + Static Assets + D1 + Queues；不依赖原作者网站、Astro、Codex CLI或本机私有Markdown工作区。

云端正文以当前访客的D1记录为唯一事实源，不能套用根目录仅适用于本地版的Markdown存储路径。用户行为与事实边界继续遵守根约定：历史选填、三项个人说明书必填、仅本人确认已发的最终稿作为后续参考、不操作微信、不编造经历、不自动重试付费模型。

密钥仅从部署者设置的Cloudflare Secret或被Git忽略的本地 `.dev.vars` 读取；不得读取原作者密钥、生产数据库、网站配置或私人素材来完成配置。不要记录请求正文、Cookie、认证头或模型推理。

修改后在本目录运行 `npm ci`、`npm test`、`npm run deploy:check`。这些检查不能声称生产部署、真实模型调用或浏览器交互已通过。远程资源创建、迁移和部署须在对应部署授权覆盖下执行；代码上传GitHub不自动包含生产发布授权。

数据库通过新迁移演进，不改写已应用迁移；升级前备份，回滚Worker不删除D1数据。独立队列只处理Moments消息，不能引入原网站语义、文章、站长或回源处理器。
