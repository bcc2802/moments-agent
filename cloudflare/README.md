# 云端朋友圈工作台

把朋友圈写作工作台部署到自己的Cloudflare账号，通过HTTPS链接使用。部署后无需保持本机运行，访客分别填写个人说明书、生成三种切口、润色和保留稿件。

这是Worker + Static Assets + D1 + Queues的独立工程，不依赖个人网站、Astro或Codex CLI。页面位于 `/moments/`，根路径会自动跳转。网页使用部署者自己配置的智谱 `glm-5.3-flash` 额度；仓库不提供账号、密钥、数据库或模型额度。

## 开始部署

准备Node.js 24、npm、可用的Cloudflare账号及本人智谱API Key，然后按[部署指南](docs/DEPLOY.md)创建独立数据库、队列和Secret。Cloudflare与智谱的使用费用由部署者承担。

```powershell
cd cloudflare
npm ci
npm test
npm run deploy:check
```

上面只验证代码与打包，不会创建远程资源、部署网站或调用模型。模板中的D1 ID是占位符，`npm run deploy` 会在填写自己的ID之前拒绝正式发布。

## 使用方式

1. 打开部署后的 `/moments/`，保存身份与业务、目标读者、表达偏好三项红字必填资料。
2. 直接在工作台输入本次事实、材料和想法，生成“讲过程 / 说判断 / 代入读者场景”三种文案；历史作品选填。
3. 在对应稿件选择口语、真实或专业润色，或填写具体改稿意见。任务浮层显示实际阶段与用时，切换导航仍可见。
4. 本人实际发表后，再明确确认已发。只有确认已发且正文匹配的最终稿自动进入后续参考素材；保存未发终稿、保留草稿均不等于已发。

数据保存于部署者的D1中，按浏览器访客隔离，不会作为公开文章或搜索内容。身份由30天签名Cookie维持；**清理Cookie、更换浏览器或身份过期后没有账号恢复入口**，重要稿件请另存。不能将本地Markdown目录直接导入云端数据库。

默认每日额度是每访客5次、每IP20次、全站100次，生成与润色共用；按北京时间日期计数。它限制请求数，不承诺固定账单上限。模型材料会发送给智谱，切勿上传凭证或未获授权的私人资料。运行边界、成本、故障和回滚见[运维指南](docs/OPERATIONS.md)。

## 工程入口

| 目录 | 职责 |
|---|---|
| `worker/` | 请求、访客会话、限额、稿件、队列和智谱连接 |
| `public/moments/` | 可直接使用的工作台界面 |
| `migrations/` | 仅本应用的D1结构 |
| `test/` | 合成资料的SQLite、模型传输与入口测试 |

保留迁移编号 `0011` 是为了对应已验证的工作台迁移来源；独立新库可以直接以它作为首个迁移，不需要原网站的 `0001`—`0010`。本目录没有原网站的内容、运维凭证或私人工作区。
