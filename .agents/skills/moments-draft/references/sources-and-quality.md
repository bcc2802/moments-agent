# 来源与写作质量

每句话都要能区分本人事实、本人观点、来源主张和编辑提议。不能补造客户、业绩、收入、节省时间、人物心理、发布日期或个人承诺。

公开链接的来源约定：实际读取正文后构造核心`external_source`，至少包括`kind:user_link`、原URL、platform、title、`content_published_at`与`event_at`（未知null）、`risk_level`、`claims`、`personal_view`。claims只支持`SOURCE_REPORTED`或`PRIMARY_REVIEWED`；只有真的回读一手材料才填写primary_url和review_note。未核验的重要事实应停在缺口说明，不能编造第三种basis绕过门槛。平台标题、搜索摘要和第三方转述不能代替实际核验。没有给本人观点时不能写“我一直认为”。具体字段按`moments.py`中的external_context检查，不绕过错误。

本人经历来自本次提供材料，或已授权日记录定位；个人资料和历史作品不是新事件证据。来源缺失、变更、读取失败均说明，不擅自扫其他目录补故事。

三稿应实质不同，可分别采用过程、判断和读者场景；没有经历不强凑过程稿。短句、口语、一个主旨，长度按本人偏好，70–220字仅软参考。不默认强行营销、引导私聊或夸大成效。示例风格不能覆盖本人明确偏好。

提交后完整展示三个原编号；先交付正文，再处理可选媒体。本人最终文字优先，姓名、标点、分行原样保存。机械测试不能证明语气像本人或有商业效果。
