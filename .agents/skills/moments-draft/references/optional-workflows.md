# 可选能力入口

先读代码根`docs/OPTIONAL_FEATURES.md`、`docs/HOT_SOURCES.md`及实际组件配置。默认基础闭环使用本人材料，不要求安装热点、Pillow、飞书或Obsidian CLI。

## 七源热点

仅百度、牛客、虎扑、掘金、少数派、微博、知乎，来源集合在`moments_platforms.py`。当前客户端要求精确七源并关闭RSS、定时、通知、AI分析和翻译。上游TrendRadar是单独安装的外部组件；不可将别人的凭证或本机路径带到发行版。

优先验证组件；未配置时不能声称抓取成功。完成实际采集后按核心`workflow-prepare`保存完整池，依据使用者的读者与偏好逐条评价，再`workflow-curate`提交完整评价，最多推荐10条，不足不凑。不能只截源前十、用关键词代替全池判断，不能把旧缓存冒充当日。

编辑规则为内容适配60＋最匹配赛道40，门槛沿用代码。A/B/C可作为实践/专业判断/工作生活三个演示方向，具体相关性由使用者画像和本轮材料决定，不继承原作者经历。评价字段以脚本/合成测试为准。扩源尚未实施，不能在配置中写一个平台名就宣称已支持。

选热点后用`preparation-start`持久化明确批次/候选及媒体要求，实际读取原文，以`preparation-update`记录来源核验和本人表达，来源与本人表达齐备才生成三稿。恢复用`preparation-resume`的next_action，不重采、不重排当前编号。旧run只能查看，不能覆盖后来稿件或发表状态。

## 配图

基础教程可不配图。已有图片仅在本人授权范围内使用；本地处理需要Pillow。网页采集需要兼容浏览器工具，并非Python脚本自带。真实网页截图保留原内容，原标题红框不得改写事实；不能用生成图片冒充现场。公开再分发还需核对素材权利。

媒体按明确轮号保存，准备不代表采用；实际使用图片只认本人明确报告，不推断整组已发。媒体失败不阻塞已完成正文交付。

## 飞书

本候选保留核心任务存档接口，未打包作者机器上的Hermes/飞书机器人托管及私人配置。新用户飞书部署是高级适配路线，未做跨环境支持验收。独立终稿以`_tasks/<task_id>/final.md`为事实源；不要建立第二份发布台账。

## 电影日签

`python -m daily_card` 只在本地画早安海报，说明见 `docs/DAILY_CARD.md`。不要把它接进写作轮次、素材库、微信发送或 Cloudflare Cron。没有 `TMDB_API_KEY` 时用内置片单；生成画面不能说成影片剧照或现场照片。
