## 已有模型与界面证据

2026-10-30 的原工作区曾使用合成材料真实完成智谱 GLM-5.3-Flash 生成三稿和单稿润色，并观察三项说明书、历史选填、三切口及跨页面任务状态。云端曾完成受控访客 API 全流程、隔离和额度检查。这些属于导出前版本的历史证据，不代替本次独立发行验收。

本次打包不调用站长或使用者的付费模型，不操作微信，也不模拟任何真实用户已经发表。测试中的已发确认仅发生在隔离的合成工作区或内存 SQLite 中。

## 验证边界

- 机械测试不能证明真人文风、经营成效或服务持续可用。
- 本地基础发行使用标准库回归；可选图片测试的跳过与未加载项目会明确列出。
- 新机器的人工安装、其他操作系统、七源长期在线稳定性、通用配图和飞书部署不属于本次默认已验证能力。
- 独立云端包将验证配置和本地运行时；不会为发行另建生产数据库、部署第二个公开站点或迁移原站数据。

## 复现

在项目根目录运行：

```powershell
python -B scripts/release.py check
python -B scripts/verify_release.py --core-only --output-dir <代码目录外的新目录>
```

在 `cloudflare` 目录运行：

```powershell
npm ci
npm test
npm run deploy:check
```

CI 使用合成数据和模型测试替身，代码提交不携带模型密钥或生产部署权限。
