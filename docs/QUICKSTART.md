# 第一轮：用本机网页工作台写一条

本页的路径、命令和扩展配置针对本地版。云端版使用 D1 与访客 Cookie，部署和数据边界见[云端教程](../cloudflare/README.md)及[隐私说明](PRIVACY.md)。

目标是用自己的私有工作区完成“三稿 → 修改 → 终稿 → 恢复”。先用自己可以交给模型处理的一段材料完成写作，再按需配置热点、配图或飞书。

## 推荐：双击入口

1. 准备 Windows、Python 3.11/3.12/3.13，并选择自己的智谱 GLM-5.3-Flash API 或已登录的原生 Codex CLI ≥0.165.0。先按[安装与配置指南](INSTALL.md)核对；使用智谱不要求安装Codex CLI。模型用量或API费用按所选服务计算，本工具不附送额度。
2. 双击项目根目录 `start.cmd`，保持启动窗口运行，浏览器将打开本机工作台。关闭服务可回启动窗口按`Ctrl+C`。不要分享启动链接。
3. 打开“个人说明书”，填写三项红字“必填”：身份与业务、目标读者、表达偏好，点击保存。旧Markdown中已有的其他资料仍保留。
4. 历史作品选填。可以稍后到“素材库”选择 `.md/.txt` 文件，或粘贴本人认可、允许参考的作品；导入不代表确认已发表。
5. 在工作台选择写作模型，在首页直接写本次材料与观点，点击“生成三条朋友圈”。三稿结果也在这里；“开始写作”入口只是定位这个工作台。页面说明哪些上下文会交给所选服务，历史不会整库发送。
6. 选看一条；可以复制正文，展开“让AI改一改”选择“更口语化 / 更真实 / 更专业”并补充意见，也可以手工保存终稿。预设只改变表达，不新增经历、客户或效果。选择、复制和保存终稿都不表示发表。
7. 想留待以后用，点“保留”。未发稿仍按候选与显式保留规则管理，不进入素材库或后续AI参考。
8. 本人确实手动发表后，才勾选已经发出并确认；素材库只收录这条本人确认已发的最终正文，不连带收录同轮其他候选。
9. 刷新页面或重新运行同一启动器，在“我的内容”回看稿件，在“素材库”回看导入原文和已发最终稿。页面搜索只覆盖已加载内容；完整查询仍可按文档使用工作区入口。

生成按钮不可用时，先看三项必填资料是否已保存、所选模型是否已配置并可用，再刷新状态；不需要为启用按钮上传历史。失败会展示原因，不会以固定三稿替代模型输出，也不会自动换到另一家服务。

默认工作区是用户目录的 `MomentsAgent`；重开不覆盖已有内容。首次指引会显示必填说明书的准备状态，历史上传标为选填。

提交后，页面悬浮状态显示模型正在执行的真实阶段与已用时。切到素材库、个人说明书或我的内容仍能看到；任务中请勿重复提交。短暂失联不等于任务已停止，可继续查看状态，等成功或明确失败后再处理。三稿用“讲过程、说判断、代入读者场景”的醒目标题和视觉标记区分，不只依赖颜色。

导入文本以Markdown副本存到本机，发表状态保持未知，不覆盖原文件。生成最多读取两篇参考：有合格已发稿时可结合一篇导入原文和一篇已发最终稿；没有合适参考时仅依靠说明书与当次材料。未发稿不参与后续参考，这不等于训练基础模型。敏感材料先看[隐私说明](PRIVACY.md)。

网页不操作微信。“我已经手动发出”只有在你实际发布后再勾选；没有真实发表时刻，保持未知。三稿默认是临时候选，换新轮或确认已发后，未选且未保留的稿会先备份再收尾，原编号不重排。

下面是给希望自行指定工作区、或使用Codex对话入口的操作方法；日常使用网页不必填写这些参数。

## 对话与终端入口：准备运行条件

在 Windows 上用 Codex 打开候选项目目录。对话入口需要可用的Codex账号或宿主模型访问方式，以及可运行的 Python。存储脚本负责留痕与恢复；网页按钮独立使用所选智谱API或Codex CLI。可在终端用 `python --version` 检查 Python 是否可调用；准确支持版本以候选验证记录为准。

不用先安装 Obsidian，也不用把全部日记交给 Agent。云端模型会处理你交给它的上下文，先看[隐私说明](PRIVACY.md)。

## 新建指定的演示工作区

推荐说：

> 请按本项目Skill，帮我在代码目录以外新建演示工作区，使用合成材料，不连接私人目录。初始化后做只读检查，告诉我位置和结果。

若由终端初始化，在项目根目录 PowerShell 执行：

```powershell
$MomentsWorkspace = Join-Path $env:USERPROFILE 'moments-demo'
python -B .\scripts\workspace.py init --workspace $MomentsWorkspace --demo
python -B .\scripts\workspace.py doctor --workspace $MomentsWorkspace
```

这会使用用户目录下的新文件夹；父目录需已存在。文件夹已经存在但不是本工具的合格工作区时会拒绝，包括已有空文件夹。换一个未被使用的新名字即可，不要删除原文件来绕过检查。已初始化的合格工作区重复运行不会覆盖，也不会补充演示数据。

工具返回 JSON。成功通常为 `status: OK`；重复合格初始化为 `ALREADY_INITIALIZED`。错误与部分读取失败用非零退出码提示，不能只看到有输出就当成功。初始化不会联网采集或生成草稿。

工作区内应有：

```text
config.json
state.json
personal/author.md
personal/audience.md
inputs/daily/
inputs/history/01.md ... 05.md
archive/_style/00_写作偏好.md
archive/00_朋友圈内容库.md
```

个人资料模板与五篇历史均明确标为合成。`--demo` 只复制历史文件，不把它们登记为已发稿。不要手动修改工具所有权标记来接管其他目录。

如果从终端初始化，把实际工作区路径告诉 Codex。Skill 可以在项目本机路径文件中记住该位置；这个文件不属于可公开发行内容。重新定位后，写稿前仍需从工作区检查真实状态。

## 请 Agent 读取资料并写三稿

对 Codex 说：

> 使用刚才的演示工作区。按 examples/SCENARIO.md 的合成顾问和本次材料写三条不同切口的朋友圈。先读个人说明书、目标读者和写作偏好，检索并回读相关合成历史。保存后展示完整三稿、编号、标签和存档位置。不配图，不采热点，不操作微信。

这个请求明确授权使用虚构人物来演示。正式写真人内容时，模板必须先替换为本人资料。

检查三条是否分别从过程、判断、读者场景切入；有没有编造客户、收入、节省时间或使用效果。脚本成功保存只能证明文件操作成功，正文是否值得发仍由你审阅。

## 修改并保存终稿

> 修改2：保留“清单不能替代沟通”，删掉空泛评价，再具体一点。

Agent 应只改原第2稿，保存回读并展示。说“选2 / 准备发2”只选看，不表示发表，也不表示长期保留。

你可以回传完整最终文字：

> 本轮选第2稿。以下是我的终稿，按原字、标点和分行保存，暂未发表：……

想留着以后发，明确说“保留2”。默认三稿是临时候选，换新轮或确认已发后，未选且未保留的稿会先备份再收尾。

## 验证恢复和模拟收尾

退出本次会话后重新打开项目，告诉 Codex 演示工作区位置并说：

> 恢复这个工作区，查看活动轮和本轮第2稿，从文件回读，不按旧对话猜编号。

如要检查发布状态机制，只在这个演示工作区说：

> 仍是合成演示，请将本轮第2稿按模拟已发确认处理，检查备份、未选稿收尾和重复确认。此操作不代表真人发布。

模拟结果必须标明模拟。真实使用中只有本人明确报告实际已发，Agent 才能变更发表状态；没有真实发表时刻则保持未知。清理后不重排原稿编号。

## 对话入口开始正式使用

另建一个新工作区，初始化时省略 `--demo`。模板不能当作本人事实；先填写自己的身份与业务、目标读者和表达偏好，再给一小段愿意交给所用模型的本次材料即可。历史作品选填，可日后补充，网页可直接完成这些步骤。
