# 发行检查表

首次公开发行决定见 [RELEASE_DECISION.md](RELEASE_DECISION.md)。这是每次发行复用的检查表，复选框默认未填写；具体版本实际执行结果见[验证记录](VALIDATION.md)，不以文件存在或历史数字自动判为通过。

## 版本、文档与范围

- [ ] 版本、目标提交、白名单和逐文件哈希一致，本地版与云端版都已收录。
- [ ] README 可直接找到安装、云端部署、模型要求、数据位置与停止方式。
- [ ] 三项说明书必填、历史选填、三切口、润色预设和已发入库规则与代码一致。
- [ ] LICENSE、第三方清单、贡献和安全入口完整，内部链接有效。
- [ ] 可选热点、配图与飞书的边界明确，未验证能力未当作默认已交付。

## 隐私与权利

- [ ] 即将推送的文件及独立 Git 历史不含密钥、真实资料、稿件、私人配置、数据库、备份或日志。
- [ ] 云端模板没有维护者真实资源 ID、域名绑定、账号标识或生产 Secrets。
- [ ] 合成示例和截图未伪称真人案例，新增第三方内容有来源与必要声明。
- [ ] 发行包只包含明确白名单，不因 `.gitignore` 存在就省略人工核查。

## 本地验证

- [ ] 在新目录解压发行包，核对 MANIFEST 与 SHA256SUMS。
- [ ] 本地核心回归、工作区初始化与合成生命周期通过，真实用户数据未用于测试。
- [ ] Windows Python 3.11／3.12／3.13 的 GitHub CI 通过；跳过项与环境限制单独记录。
- [ ] 启动器、资料填写、历史可跳过、三稿、修改、手工终稿、保留和已发语义清楚。
- [ ] 只有本人明确已发且指纹吻合的终稿成为参考，未发稿不进入后续上下文。

## 云端验证

- [ ] 锁文件安装、Node 24 测试、Worker 入口、静态资源、迁移初始化和 Wrangler dry-run 通过。
- [ ] 访客隔离、Origin／CSRF、重复任务、额度并发、队列投递及错误处理测试通过。
- [ ] 测试未读取生产数据、调用真实付费模型、创建远程资源或部署现有网站。
- [ ] 教程明确由安装者自备账号、Secrets、D1 和队列，没有承诺附送维护者额度。

## 远程发布与回读

- [ ] GitHub 可见性、源码树、MIT、目标提交与本地审核结果一致，真实 CI 全部通过。
- [ ] Release 指向已验证的提交，附件为完整 ZIP、MANIFEST 与 SHA256SUMS。
- [ ] 从 GitHub 重新下载附件，验证哈希、文件清单、链接与解压流程。
- [ ] 记录真实测试、跳过项和未验证限制；陌生用户独立安装、真人文风及经营效果不冒充已验收。
- [ ] 本次未发表营销文章、操作微信或改变现有网站部署。

失败或外部写入状态不确定时，先保留证据并重新读取结果，不以重复点击代替核验。后续新增发布对象或扩大公开范围时，重新核对授权。
