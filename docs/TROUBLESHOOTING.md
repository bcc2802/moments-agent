# 常见问题

本页的路径、命令和扩展配置针对本地版。云端版使用 D1 与访客 Cookie，部署和数据边界见[云端教程](../cloudflare/README.md)及[隐私说明](PRIVACY.md)。

先对Codex说“检查当前朋友圈工作区，做只读诊断，不自动修复或发布”。查看真实错误码和覆盖范围，再决定下一步；不要把无法读取说成内容为空。

| 情况 | 先检查 | 怎样继续 |
|---|---|---|
| `python` 不可调用 | 终端是否能执行 `python --version` | 使用已安装的解释器；确需安装时先明确版本和位置，不用改全局环境来猜修复 |
| Codex能读文件却不生成文案 | 宿主账号、额度和模型是否可用 | 脚本只负责存储；恢复宿主能力后继续，不把固定示例冒充模型输出 |
| 初始化拒绝路径 | 是否绝对路径、父目录存在、代码目录外、没有已有未知目录或链接 | 选一个新的普通目录；不要改标记或递归删除旧目录绕过保护 |
| 返回 `ALREADY_INITIALIZED` | 这是否确为要使用的合格工作区 | 继续只读检查；它不会覆盖资料，也不会补充`--demo`示例 |
| 初始化中断且 `changed: true` | 新目录是否只完成了一部分 | 保留现场，检查缺项；不假称自动回滚成功，也不自动清空目录 |
| profile仍显示合成顾问 | 是否已经换成本人资料 | 演示可继续使用；正式写作前替换，不能直接当本人身份 |
| 历史查询 `PARTIAL` | `coverage_complete`、失败来源与大小/数量限制 | 处理具体不可读或超限来源，再重新查询；不要断言没有作品 |
| 历史ID失效 | 原文件是否移动或改名 | 重查当前文件并回读；不用旧摘录替代失效原文 |
| 报疑似凭证或隐私内容 | 文件名/正文是否混入不该读取的信息 | 由本人处理公开范围；不让Agent展示值或绕过检查 |
| 不知道“第2条”属于哪轮 | state、存档、明确轮号是否一致 | 定位真实轮次；指针不唯一时只澄清编号所属，不猜最新文件 |
| 未选的第1/3稿不见了 | 是否有明确退稿记录与可核验备份 | 这是可能的正常收尾；不重排原编号或静默恢复已清理候选 |
| 说“准备发”后仍是待发布 | 本人是否实际报告已发 | 这是预期行为。选择、复制、准备均不表示发表 |
| 原文或网页打不开 | 网络、登录、资源权限、类型和超时 | 说明实际缺口；可换本人明确提供的材料，不把标题当已核实全文 |
| 热点不可用 | 是否完成独立上游安装与七源配置 | 走[热点教程](HOT_SOURCES.md)；基础写作继续，不用旧榜补齐 |
| 没有Obsidian CLI | 是否只是想读普通Markdown | 使用普通文件夹和内部查询，说明不能使用的CLI能力 |
| 图片/飞书不可用 | 是否只是保留代码接口、尚未配置环境 | 看[可选功能](OPTIONAL_FEATURES.md)，不用可选组件也能完成基础写作 |

工作区只读诊断命令：

```powershell
python -B .\scripts\workspace.py doctor --workspace $MomentsWorkspace
```

`$MomentsWorkspace` 应是当前终端已经设置的实际工作区绝对路径；否则直接填自己的路径。JSON返回 `ERROR`、`PARTIAL` 或诊断的 `NEEDS_ATTENTION`、退出码非零都需要查看具体问题，不能只看最后一行有JSON就认为完成。

备份和恢复涉及真实稿件，先展示将影响的轮次、文件与现有证据，再执行已授权的必要动作。不要用整目录旧备份覆盖后来稿件，也不要删除state来试图解决所有恢复问题。

反馈问题时提供候选版本、Python/宿主、错误码、脱敏步骤和合成复现。不要粘贴完整个人说明书、历史作品、私有路径、群ID或凭证。开发者检查见[开发入口](DEVELOPER.md)。
