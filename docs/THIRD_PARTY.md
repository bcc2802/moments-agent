# 第三方组件与服务

本清单说明发行边界。项目自有内容采用 [MIT](../LICENSE)；外部依赖和服务继续适用各自的许可与条款。仓库不附带解释器、模型、第三方 CLI 二进制、真实平台资料或生产账号配置。

| 对象 | 用途与分发方式 | 使用者需要核对 |
| --- | --- | --- |
| Python 3.11／3.12／3.13 | 本地版运行环境，由使用者自行安装；基础写作使用标准库 | 选用系统和解释器版本；发行验证见[验证记录](VALIDATION.md) |
| 智谱 GLM-5.3-Flash API | 本地或云端后端调用[官方通用接口](https://docs.bigmodel.cn/cn/guide/develop/http/introduction)；不分发模型、SDK、账号或额度 | API 权限、计费、数据处理规则与可用性；自备密钥。GLM Coding Plan 与通用 API 端点及权限不要混同 |
| Codex CLI／Agent 宿主 | 本地版可选写作路线，最低原生 CLI 0.165.0；不随包提供运行时或认证 | 依[安装指南](INSTALL.md)配置本人账号，核对具体版本与模型权限。云端版不调用 Codex |
| Node.js 24 | 云端开发、测试和部署工具环境，不随包提供运行时 | 使用受支持环境，并按锁文件安装开发依赖 |
| Wrangler 4.156.0 | Cloudflare 官方开发与部署工具，许可证 `MIT OR Apache-2.0`；云端固定直接版本与锁文件，不提交 node_modules | 按锁文件安装后，依[云端教程](../cloudflare/README.md)配置自己的 Cloudflare 账号和资源；传递依赖仍适用各自许可 |
| Cloudflare Workers／D1／Queues | 云端运行、访客数据存储与后台写作任务；本项目提供适配代码，不分发这些服务 | 服务条款、资源限制、费用、账号权限、Secrets 与备份策略 |
| GitHub Actions | 官方 checkout、setup-python、setup-node 用于维护验证，固定完整提交 SHA；不属于产品运行依赖 | 查看工作流及其上游许可，保持最小权限；无生产密钥、真实模型调用或自动部署 |
| Pillow | 本地图片处理的可选依赖；基础文字流程不需要，不随包附带 | 启用时选定版本并核对 [Pillow 许可](https://pillow.readthedocs.io/en/stable/about.html#license)；基础 CI 不将可选图片测试写成已通过 |
| TrendRadar／NewsNow／热榜来源 | 本地版可选外部热点能力，保留调用接口，不复制其源码或数据集 | 按[热点指南](HOT_SOURCES.md)准备独立环境、核对实际版本许可与平台规则。TrendRadar 历史兼容基线见该指南，不代表已为新机器部署 |
| Hermes／飞书 CLI | 本地可选消息适配参考，发行包不包含私人桥接、网关或安装包 | 单独完成版本许可、身份、权限、托管和端到端验收，不宣传为云端首版内置能力 |
| 合成示例与界面截图 | 理解流程、文档和测试，不使用维护者私人原文 | 保留合成属性；不作为真实客户、真人文风、发表或经营成效证据 |

云端锁文件记录开发工具的完整依赖，业务运行没有生产 npm 依赖。实际安装数量会随操作系统及可选依赖而变化；版本以发行锁文件为准，后续升级须重新核对。

## 素材权利与软件许可分开

能访问一个页面不等于可以复制其全文或图片，聚合接口可调用也不等于获得无限采集或再分发权。热点只是线索，重要事实需要阅读原文并核验。第三方照片、截图、评论、商标和人物隐私应分别核对，不继承项目 MIT 许可。

## 不随包分发

真实说明书、客户信息、历史朋友圈、日记、反馈、账号和群标识、登录态、生产配置、密钥、数据库、备份、运行日志、网页全文与图片数据池均不进入发行白名单。

新增或升级依赖、复制第三方片段或扩大分发形式时，更新本表和[发行检查](RELEASE_CHECKLIST.md)，记录实际固定版本与必要声明。
