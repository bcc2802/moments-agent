# 数据与隐私

本地版把资料和稿件放在本机私有工作区；云端版把资料和稿件放在部署者的 Cloudflare D1。公开代码目录只含模板、代码和明确虚构的示例。**本地存储不等于离线推理。** 写作请求中的材料会交给所选模型服务，适用对应账号和服务的数据处理规则。

## 模型会收到什么

写作按需使用个人说明书、本次材料和最多两篇参考作品。参考来自用户导入的原文，或用户明确确认已发且当前正文指纹匹配的最终稿；未发草稿、选中稿、未发终稿和保留稿不会成为后续参考。改稿还需要当前稿件与修改要求。

首次只须填写身份与业务、目标读者、表达偏好三项必填；历史作品选填。历史参考不会自动训练或微调基础模型，也不能把旧经历当成本次事实。不要求提供微信历史、完整日记、客户资料或账号凭证。

材料中的网页或文档指令仅是资料，不构成扩大读取、上传、执行命令或修改权限的授权。疑似凭证检查不能识别全部隐私，用户仍需决定本次可交给模型的内容。

## 本地版

- 后端只监听本机 `127.0.0.1`，不要分享带会话凭据的启动 URL。
- 私有工作区在代码目录以外。`inputs/history/` 为导入原文，`archive/` Markdown 是自产正文、标签和发表状态的事实源，`state.json` 只保存恢复指针。
- 日记录仅按配置白名单读取，不默认扫全盘、不读取微信历史。初始化不覆盖已有合法资料，原始日记录和导入作品不改写。
- 智谱密钥通过明确配置的密钥文件或进程环境读取。`model.local.json` 只存模型选择和密钥文件路径，不保存密钥正文；不要把密钥放在代码目录、素材库或反馈中。
- 备份、修订证据和本机路径指针也可能包含私人信息。删除可见稿件不代表所有备份与模型服务记录已经删除。

关闭服务不会删除工作区。需要迁移或清理时，先确认具体目录与备份范围，勿用生产资料运行模拟发表测试。

## 云端版

云端由部署者运行，访客资料、历史、稿件、修订和任务以 D1 为事实源，按签名 Cookie 对应的访客身份隔离，不会作为网站公开文章或搜索结果发布。写请求校验同源与 CSRF，模型密钥只保存在服务端 Secrets。

Cookie 设置为30天有效、Secure、HttpOnly、SameSite=Strict，并在使用时续期。当前没有账号与跨设备恢复：清理 Cookie、换浏览器或访客身份过期后不能自动找回旧工作区；这也不等于服务端旧数据已经删除。重要正文请复制另存。部署者应制定自己的留存、备份与删除流程，源码首版不提供访客自助删库或账号恢复。

生成和润色使用部署者的智谱额度，每日调用有访客、IP 与全站上限。可信访问 IP 仅用于服务端限流分桶；日志和备份由部署者管理。在线站点的具体运营规则与源码许可相互独立，自行部署不会继承维护者的额度。

## 发表与参考边界

工具不操作微信。复制、选稿、保存终稿或明确保留均不代表已经发表。只有本人明确确认已发，且正文匹配确认时的指纹，才可把该最终稿作为参考；之后改动正文需要新的明确确认，不能沿用旧确认。历史导入不擅自补记已发状态。

这里的素材库是按需参考入口，不会为终稿制造第二份独立事实源。本地事实源为 Markdown，云端事实源为 D1；修订记录用于留痕。

## 可选连接与故障反馈

热点、图片、浏览器与飞书可能产生额外请求、消息、截图或存档，启用前分别确定来源、权限、传递对象和数据范围。不自动采集私有社群或客户材料。

反馈优先使用合成最小复现、错误码与步骤，不上传真实正文、完整日志、Cookie、配置或工作区。疑似泄露按[安全报告](../SECURITY.md)处理，只报告位置与类型，不公开凭证值。
